# Metsamor Nature Hub

Build a functioning, premium-quality website for “Metsamor — Taking Action for Nature | COP17”, following the full specification in the attached brief. The brief is also included as the user’s pasted text in this conversation. Use React + TypeScript, responsive editorial design, Armenian by default plus English and Russian, official COP17 color palette, elegant skippable nature intro animation, treasure cards/detail views, and a data-driven directory of only current Metsamor Community settlements. Absolutely no maps or geographic visualizations, no public admin button, no invented contacts, statistics, verified-location claims, or settlements from other communities. Clearly label unverified example content as drafts/placeholders. Prepare maintainable data access and safe Supabase integration points, without pretending persistence is configured. Build the actual working frontend, not just a mockup.
